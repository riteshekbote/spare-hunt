## LEAD 1: CORS reflect-any-origin with credentials on entire /v1 API surface
**Source:** bigpickle, laguna, nemotron3 (confirmed by all 3 models, multiple live probes)

| Q | Answer |
|---|--------|
| Q1 Scope | **YES** — api.sparelabs.com/v1/** is in-scope |
| Q2 Reachable | **YES** — public, unauthenticated OPTIONS/GET with arbitrary Origin |
| Q3 Impact | **YES** — any malicious site can issue credentialed cross-origin read+write calls against the entire /v1 API if a victim's browser auto-attaches credentials (cookie or token-holder). Methods GET,HEAD,PUT,PATCH,POST,DELETE + Authorization header all permitted. |
| Q4 Proof passive | **YES** — `curl -X OPTIONS -H "Origin: https://evil.example.com" -H "Access-Control-Request-Method: POST" -H "Access-Control-Request-Headers: Authorization" https://api.sparelabs.com/v1/journeys/requests -D - -o /dev/null` returns `access-control-allow-origin: https://evil.example.com`, `access-control-allow-credentials: true`, `access-control-allow-methods: GET,HEAD,PUT,PATCH,POST,DELETE`, `access-control-allow-headers: Authorization`. Also confirmed on GET. Stable across 401/404/200 paths. |
| Q5 Novel | **YES** — no evidence of prior report |
| Q6 Not rejected | **YES** — real misconfig (not best-practice/Rate-limit) |
| Q7 Triager accept | **YES** — classic A05:2021 CORS misconfig with credentials, uniformly applied via envoy gateway |

**Verdict: ✅ VALID**

**Minimal read-only proof:** OPTIONS preflight with `Origin: https://evil.example.com` on any /v1/* route; observe ACAO reflects origin + ACAC true + all methods + Authorization header allowed. Repeat on auth-gated route (/v1/journeys/requests) — same reflection confirms API-scoped middleware.

**Impact:** Cross-origin authenticated read+write of user/rider/journey/org data by any malicious origin. Requires victim browser to hold auto-attaching credentials (cookie or in-page token holder); no credential vector confirmed yet (Bearer-only observed, no Set-Cookie), so current exploitability is theoretical but class is CRITICAL if any credential vector appears.

**CVSS 3.1:** `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:N` — **8.1 (High)** (origin reflection + credentials + write methods; UI:R because victim must visit attacker page)

**Report to:** Spare security channel (per scope.yml; disclosure_policy TBD — request confirmation before sending details)
